# Aditya Chauhan: Portfolio

React + Vite + Tailwind CSS.

## Run locally
    npm install
    npm run dev

## Update your details
Edit only `src/data/portfolio.js`: skills, projects, experience, links, bio.
- Set `showPhone: true` to show your phone number.
- Replace the placeholder `github` links in `projects` with the exact repo URLs.
- Add your certificate URL in `experience[0].link`.

## Deploy
Push to GitHub, then import the repo on Vercel or Netlify (build: `npm run build`, output: `dist`).
